# 🚀 OrbitCraft — Space-Themed Web Application

A modern, high-performance web application built with **React**, **Ant Design**, and **Lucide Icons**, wrapped in a sleek glassmorphism space-age aesthetic.

---

## 🌟 Features

* **Cosmic UI/UX Design:** Dark-mode glassmorphism layout with floating animations and glow effects.
* **Responsive Layout:** Optimized for all screen sizes using CSS Grid and Flexbox.
* **Interactive Components:**
  * 🌌 **Home Page:** Dynamic hero section, tech stack highlights, and mission showcase.
  * 🪐 **About Page:** Team stats, core directives, and mission philosophy.
  * ⚙️ **Services Page:** Custom interactive service cards with features list.
  * 📡 **Contact Form:** Ant Design form styled for space-themed transmissions.
  * 🛸 **404 Page:** Interactive "Lost in Deep Space" error handler with direct search bar.

---

## 🛠️ Tech Stack

* **Frontend Framework:** React.js
* **UI Component Library:** Ant Design (`antd`)
* **Icons:** Lucide React (`lucide-react`)
* **Styling:** Custom CSS (CSS Modules / Plain CSS with Glassmorphism)
